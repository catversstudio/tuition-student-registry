# Tuition Student Registry

An Android app by **Catvers Studio** for tuition teachers to manage their student records in one place.

## About

- 📚 Keep student records organised digitally — no more paper registers
- 🎓 Built for small tuition classes and individual tutors
- 🛠️ Built with **Kotlin + Jetpack Compose**, with **Firebase** for secure cloud data
